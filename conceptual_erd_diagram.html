Level 1 Conceptual Data Model (ERD)

San Isidro National High School – Student Entrance Monitoring System (SEMSYSTEM)

Academic Note on Conceptual ERD Compliance: Primary Key (PK) labels, Foreign Key (FK) labels, and technical SQL data types are omitted. The model highlights business entities, conceptual attributes, operational relationships, and the Associative Entity (GATE_LOG).

3. Relationship Discussion & Associative Entity Rules

1. GRADE_LEVEL contains SECTION (1-to-Many): One Grade Level contains multiple class sections. Each section belongs to exactly one Grade Level.
2. SECTION enrolls STUDENT (1-to-Many): One Section enrolls multiple students. Each student belongs to one designated class section.
3. USER_ACCOUNT registers STUDENT (1-to-Many): One System User Account (School ICT Coordinator) registers and manages multiple student records in the database.
4. STUDENT is assigned QR_CODE (1-to-1): Each enrolled student is assigned exactly one unique QR Code credential.
5. GATE_LOG as an Associative Entity (1-to-Many): GATE_LOG functions as an Associative Entity that links a student's assigned QR_CODE with their real-time gate passage events, recording the Scan Date & Time and Gate Passage Status (ENTRY / EXIT) for every scan.

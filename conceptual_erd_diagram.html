3. Subsystem Breakdown & Relationship Discussion

📌 Module 1: Enrollment / Teachers Subsystem (`GRADE_LEVEL` ➔ `SECTION`, `TEACHER` & `ENROLLMENT`)
• GRADE_LEVEL contains SECTION (1-to-Many): Each Grade Level contains multiple class sections (connected via sections.grade_level_id Foreign Key).
• TEACHER advises SECTION (1-to-1): Assigns a Teacher Adviser to each class section.
• ENROLLMENT assigned to STUDENT (Many-to-1): Assigns the student to a Section for the given School Year.
• ENROLLMENT belongs to GRADE_LEVEL (Many-to-1): Assigns the student's designated Grade Level.
📌 Module 2: Attendance Subsystem (STUDENT ➔ QR_CODE ➔ GATE_LOG ➔ ATTENDANCE)
• STUDENT is assigned QR_CODE (1-to-1): Unique QR code issued upon enrollment.
• QR_CODE generates GATE_LOG (1-to-Many): Gate terminal records Time-In / Time-Out scan events.
• GATE_LOG compiles into ATTENDANCE (1-to-Many): Gate logs aggregate into daily student `ATTENDANCE` records on the Admin Dashboard.
• USER_ACCOUNT registers STUDENT (1-to-Many).
